=========================================================
GUIDA RAPIDA DOCKER: PHP + MYSQL (SKILLSWAP)
=========================================================

1. ACCENSIONE DATABASE
   - Vai nella cartella: [Cartella del Database]
   - Comando: 
     docker-compose -f composeMysql.yaml up -d

2. ACCENSIONE SITO PHP
   - Vai nella cartella: [Cartella del PHP]
   - Comando: 
     docker-compose -f composePHP.yaml up -d

3. CREARE IL PONTE DI RETE (DA FARE OGNI VOLTA SU PC NUOVI)
   - Puoi farlo da QUALSIASI cartella.
   - Comando: 
     docker network connect skillswapmysql_mysql_net php_container

4. ACCESSO AI SERVIZI (BROWSER)
   - Sito Web: http://localhost:9000
   - phpMyAdmin: http://localhost:8081

5. LOGIN PHPMYADMIN / CODICE PHP config.php
   - Server: mysql
   - User: admin (o root)
   - Pass: myXadmin00$ (o root)
   - DB: skillswap

6. SE DOCKER SI BLOCCA (ERRORE PORT ALREADY ALLOCATED)
   - Da qualsiasi cartella, scrivi:
     docker stop $(docker ps -aq)  [Su Mac/Linux]
     docker ps -q | ForEach-Object { docker stop $_ } [Su Windows PowerShell]

7. SE NON TROVA IL DB (ERRORE GETADDRINFO)
   - Riesegui il punto 3 (il ponte di rete).
